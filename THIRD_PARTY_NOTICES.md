# Third-party notices

The bundled o200k tokenizer data and related metadata retain the upstream MIT
notice in `packages/genesis_tokenizer/src/genesis_tokenizer/assets/TIKTOKEN_LICENSE.txt`.
Their provenance and checksum are documented in the same directory.

Original Genesis source uses Apache-2.0. Other dependencies retain their own
licenses; Apache-2.0 does not relicense third-party code or assets. The dependency
lockfile records exact versions; package metadata identifies the dependencies.
The genesis-tokenizer distribution declares Apache-2.0 AND MIT to account for
its original code and bundled MIT-licensed assets.
